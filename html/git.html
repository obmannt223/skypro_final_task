Git

  • git init - создает новый пустой репозиторий Git в текущей или указанной папке.
  • git status - проверяет текущее состояние репозитория.
  • git add - добавляет все измененные и новые файлы в индекс.
  • git commit -m "написать любое сообщение" - фиксирует изменения и создает коммит с описанием.
  • git push - отправляет сохраненные локальные коммиты на удаленный репозиторий GitHub/
